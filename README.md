# Seeing Surfaces

An interactive scanning electron microscope in the browser, built as a small science-museum exhibit. It's the sister exhibit of [Seeing with Electrons](https://advanced-em.github.io/TEM-view/) (TEM).

- **3D cutaway SEM:** Schottky gun, condenser, beam-limiting aperture, in-lens detector, scan coils, conical immersion objective, and a chamber with a tilting stage. Detectors: Everhart–Thornley (with Faraday cage), 4-quadrant BSE, EDS, an EBSD camera behind the 70°-tilted sample, and an on-axis TKD detector. Secondary electrons curve into the ETD, and Kikuchi patterns appear live on the phosphor screens. Click any label for an instrument-physics card covering how it works, typical specs, and measurement and calibration.
- **Imaging (SE · ETD, In-lens, BSE):** images formed pixel by pixel from multiscale specimens using:
  - the SE yield curve with the secant law and edge effect;
  - SE2 generated by backscattered electrons;
  - Reuter/Arnal η(Z, tilt);
  - ETD shadowing and grid bias;
  - BSE composition vs topography (A+B vs A−B) and electron-channelling contrast;
  - the probe size budget (source image, Cs, Cc, diffraction);
  - focus, stigmation, depth of field and shot noise;
  - charging of uncoated insulators above E2.
- **EBSD & TKD:** Kikuchi bands in gnomonic projection from structure factors, mixed over the interaction footprint. They're indexed live with a Hough transform and interplanar-angle voting, and compared with the true orientation. IPF, band contrast and MAD maps. TKD resolves copper nanograins that EBSD cannot.
- **EDS:** X-ray generation range, overvoltage, schematic absorption and the Duane–Hunt limit; element maps blurred by the true X-ray volume.
- **Interaction volume:** a live single-scattering Monte Carlo (screened Rutherford + Joy–Luo), with measured η, backscatter energy spectrum, and energy-deposition and φ(ρz) depth profiles.
- **Experiments:** *Charge it up* (find E2), *Nanograins: EBSD vs TKD*, and a fly-through tour.

## Run

```bash
python3 -m http.server 8767
```

Open http://localhost:8767. Three.js loads from jsDelivr. It's plain static files, so it can be hosted on GitHub Pages directly.

## Code map

| File | Role |
| --- | --- |
| `js/physics.js` | Probe formation, yields and ranges, X-ray lines, cubic crystallography, Kikuchi bands, Monte Carlo, specimens |
| `js/sim.js` | Image formation, Kikuchi pattern simulation, Hough + indexing, EBSD/TKD mapping, EDS, Monte Carlo runner |
| `js/render2d.js` | Detector views, curves, maps, spectra |
| `js/scene3d.js` | Three.js instrument, beam, signals, labels, tour |
| `js/explain.js`, `js/components.js` | Explanations and instrument-physics cards |
| `js/main.js` | State, controls, experiments, loop |
